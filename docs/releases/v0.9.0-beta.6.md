# v0.9.0-beta.6: reproducible dependencies and playlist rendering

This beta combines the software changes accepted after beta.5:

- Render HLS playlist lines directly into the output string. History pruning,
  segment grace, start offsets, discontinuity metadata and end-of-stream output
  retain their byte-exact regression coverage. No performance improvement is
  claimed without a separate measurement.
- Bound the inbound seeder test's handshake and wait for Unchoke before sending
  a request, with the owned listener stopped before assertions.
- Update igd-next to 0.18 and the source-packaging SHA2 dependency to 0.11.
  Explicit digest encoding preserves the existing lowercase SHA-256 manifest
  and archive hashes. Keep the wire protocol's compatible SHA1/RNG dependency
  versions and signing behavior unchanged.
- Keep shared fuzz/security workflow pins coherent and refresh the checkout
  action. Dependency updates do not relax the existing CI or integrity checks.

Validation for these changes is software-only: offline workspace tests,
synthetic parser/media fixtures, lint, source packaging and CI checks. This
release does not claim new device, firmware or live-stream acceptance, and
publishing it does not update a running deployment. Existing runtime defaults,
network bindings and history budgets are unchanged. Beta.5 remains available
for rollback; the stable release and `latest` container channel are unchanged.
