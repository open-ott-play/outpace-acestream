# v0.9.0-beta.8: compatible dependency maintenance

This beta updates the locked Rust dependency set while preserving the current
signing APIs and runtime defaults:

- Refresh Hyper, Tokio, rustls, serde_json, libc, roxmltree, SHA-2, want and the
  bundled root-certificate package within their compatible dependency ranges.
- Keep `ace-wire` on `rand` 0.8 and `sha1` 0.10 for RSA 0.9 and ed25519-dalek 2.
  Scoped Renovate bounds prevent those signing inputs from being upgraded
  independently of a reviewed API migration.
- Make the HTTP response-body deadline regression independent of scheduler
  timing and test order. The private request/body helpers retain the same
  connection and total-request deadlines, response checks and size limit.
- Update shared CI workflow calls, runtime inputs and the reviewed hash inventory
  as one group, retaining immutable upstream references and manual review.

No new playback feature, listener, authentication option or runtime default is
introduced. Tests use synthetic local fixtures; they do not establish universal
live-source availability or device compatibility. The beta remains a prerelease
and does not replace the stable release or container `latest` channel. Select
versioned artifacts explicitly and retain the previous verified image digest
and deployment configuration for rollback.
