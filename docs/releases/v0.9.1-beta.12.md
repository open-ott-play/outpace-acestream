# v0.9.1-beta.12: focused runtime hardening and audio inventory

Equivalent hexadecimal spellings of an Ace `cid:` VOD selector share the same
descriptor cache and resolution lock. This avoids duplicate resolution handles
when clients use different letter case. Other providers' case-sensitive IDs and
transport URLs retain their original spelling.

The public MPEG-TS `ts_pid` helper returns the null PID for input shorter than the
PID field instead of panicking. The additive `try_ts_pid` helper returns `None`
for that input, distinguishing it from a real null packet. Neither helper is a
complete transport-packet validator.

Shutdown paths for the metrics sampler, DNS service and manager reaper can
request worker shutdown when their bookkeeping locks were poisoned. This does
not interrupt an in-flight system DNS call. Ordinary processing retains its
existing invariant checks. This change does not introduce
blanket recovery of partially updated state or saturating memory accounting.
Small VOD and broadcast refactors reduce redundant lookups without changing
stream ownership or persistence ordering.

The audio inventory tool provides track inspection and saved-result comparison.
Scans against an existing daemon do not stop its shared sessions. An isolated
daemon is owned and cleaned up by the scanner, including when startup fails.
Scanner metadata distinguishes ADTS AAC from LATM and validates the PSI used to
identify tracks. See the [tool documentation](../../tools/audioscan/README.md) for
supported modes, limits and private identifier handling.

Global native AAC language preference from beta.11 remains supported. Independent
per-viewer language switching is not enabled: it requires separate audio
renditions or independently keyed packaging, rather than mutation of a shared
stream. Existing listener synchronization, replay behavior, network defaults,
stable release and container `latest` channels are unchanged.
