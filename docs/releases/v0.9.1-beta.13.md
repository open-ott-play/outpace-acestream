# v0.9.1-beta.13: compressed origin HLS playlists

Managed origin HLS now accepts gzip-compressed master and media playlists, including redirected playlists. Sources that send gzip even when the client previously requested an identity representation can now pass through the relay. Relative and signed child URLs continue to resolve against the final origin URL.

Compressed input and decoded output each have an independent 1 MiB limit. The decoder validates checksums and footers, bounds concatenated members, rejects corruption and trailing bytes, and shares the request deadline and cancellation. Rewritten playlists carry their actual uncompressed length.

Media segments and byte-range responses still require identity encoding. This change does not bypass origin authorization, decrypt protected content, restore unavailable endpoints, or change network policy.
