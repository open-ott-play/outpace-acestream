# v0.9.1-beta.4: managed HLS origins and stable retained replay

Resolved Ace descriptors can now use a bounded local HLS relay with
`OUTPACE_MANAGED_HLS=1`. Master/rendition references, relative URLs after redirects,
TS/fMP4 media, initialization maps and byte ranges are handled locally. Default
behavior remains direct handoff. Each viewer owns a cancellable relay token;
per-request admission, body/URL/cache bounds, idle/hard expiry, stable timeline
URLs and separate cache generations bound resource use. Active rendition references
and removed-media grace survive playlist refresh; capacity failure is atomic.

Retained native HLS replay accepts `position_ms`, a stable media-duration
coordinate, in addition to the existing relative `back` seconds. Exactly one is
required. Generation checks, independent viewers and failed-seek preservation
apply to both. This extension is not original Ace `liveseek`, whose sampled
client uses piece coordinates and a separate live sentinel.

Playback rejects unsupported file-selection intent before creating sessions.
Legacy malformed piece tables and multi-file data cannot be misclassified as
live; single-file VOD geometry must agree with its length. Discovery metadata
preserves known live/VOD type and verified VOD size without guessing MIME or
filenames. Duplicate query parameters are rejected, including encoded duplicates.

Qualification covers guarded acquisition, cancellation, expiry, cache age,
redirects, ranges, playlist generations, metadata and replay races. CI and RC add
FFmpeg decoding of generated TS and fMP4 through the actual managed HTTP relay.
The same-source RC continues to require normal tests, lint, security checks and
four fuzz campaigns. Release archives include complete corresponding source.

Encrypted/low-latency origin HLS, hybrid HLS-over-P2P, multifile playback, unknown
wrapper contracts, full original-engine seek semantics and persistent UTC
programme archives remain unsupported. Managed origins do not use the native
HLS replay or audio-normalization pipeline. Read [source resolution](../source-resolution.md)
and [timeshift](../timeshift.md) before integrating these distinct contracts.

This beta advances only the prerelease channel. Stable `latest` remains unchanged.
