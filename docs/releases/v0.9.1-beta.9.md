# v0.9.1-beta.9: public SDK metadata and control compatibility

Verified live media discovery supplies the MPEG-TS MIME type and a safe display
filename. Public Android clients use these fields before selecting a playback
route. They no longer receive a missing MIME value for a supported live source.
Single-file VOD metadata is kept separate; its MIME is not guessed from an extension.

Infohash and magnet metadata requests can reuse an existing verified live
descriptor. The lookup is offline, checks the exact requested hash and does not
start playback. An unknown source still has unknown properties and no invented
file table. This does not add cold-hash discovery or an HLS variant catalogue.

Managed-origin control accepts the public SDK's `api_version=2` hint. A standard
SDK stop request can therefore close its own managed HLS session instead of being
rejected before the stop handler. Duplicate parameters, unsupported versions,
invalid commands and cross-session access remain rejected.

The [public-source review](../protocol/public-code-review.md) records all twenty
repositories inventoried for this pass and the client contracts behind these
independently implemented changes. It does not claim that the public applications
contain the closed engine's complete implementation.

Playback defaults and the scope of retained replay remain unchanged. This beta
does not add player launching, multi-file VOD, persistent DVR or UTC programme
archives. Stable and container `latest` channels are not advanced.
