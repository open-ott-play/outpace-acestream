# v0.9.2-beta.1: reliable bounded lifecycle qualification

This maintenance candidate fixes the bounded memory-soak harness: socket and
observation timers now agree on a completed healthy playback window, while
stalls and incomplete progress still fail qualification. Timer cleanup is
safe on setup failures. CI now runs the lifecycle regression suite, including
the timing boundaries previously omitted from the required checks.

Static-analysis cleanup removes duplicate test configuration and unused code.
Required legacy wire-format constants and deterministic test fixtures retain
their documented roles. No listener, seeding, storage or runtime deployment
configuration changes are part of this candidate.

The same native build matrix and source/license archives remain required.
This beta is not evidence of new physical-device or live-stream acceptance.
