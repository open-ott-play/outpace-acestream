# v0.9.2: reliable lifecycle qualification

This maintenance release contains the bounded lifecycle harness and CI fixes
introduced in v0.9.2-beta.1. The runtime implementation is unchanged by the
stable version preparation.

- Successful playback windows finish consistently at socket and observation
  deadlines; genuine stalls and incomplete progress still fail qualification.
- Timer state is restored even when setup fails.
- The required CI jobs now run the memory-soak regression tests, including
  deadline boundaries, alongside the existing A/B and audio-isolation tests.
- Duplicate test configuration and unused code reported by static analysis
  have been removed. Required protocol constants and deterministic fixtures
  remain documented.

The exact stable source must pass the source RC workflow, including all
configured fuzz targets, before publication. Release packages retain the native
build matrix, checksums, matching complete-source archives, and license notices.
These automated checks do not establish new hardware or live-stream acceptance.

No deployment is performed by this source change. See the
[release process](../RELEASING.md) for publication and verification.
