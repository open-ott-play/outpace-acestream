# Outpace 0.9.3-beta.1

This beta updates the locked AES dependency from 0.9.3 to 0.9.4 in both the
engine and fuzz workspaces. The upstream patch reduces software round-key
storage and restores inlining in AES helpers. Outpace's dependency requirements,
protocol handling and device/network defaults are unchanged.

This is a dependency maintenance update, not a claim of a measured playback
speedup or a newly fixed Outpace security vulnerability. Offline qualification
does not establish live-swarm or household-device acceptance.

The beta uses the normal seven-platform binary and complete-source publication
checks. It does not replace the stable release or the container `latest` channel.
