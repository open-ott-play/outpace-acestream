# Outpace 0.9.3

Includes the AES 0.9.4 maintenance update from 0.9.3-beta.1: smaller software
round-key storage and restored helper inlining. The engine and fuzz workspaces
use the same dependency version; other external packages, dependency requirements,
protocol handling and device/network defaults are unchanged.

The software AES path is covered by existing offline wire tests. This does not
establish a live-playback speedup or household-device acceptance, and the update
is not presented as a fix for a newly identified Outpace security vulnerability.

The normal release process requires all seven binary targets and their complete
source archives. Source RC evidence remains distinct from binary publication.
