# Outpace 0.9.4-beta.1

This beta fixes resource and cache problems found during a review of the
streaming, VOD and wire-protocol code.

## Reuse retained VOD data

Cached VOD pieces larger than a peer's 16 KiB request block could be treated as
cache misses. Internal cache reads now assemble the retained chunks of a
verified piece, including a short final piece. Overlapping range requests can
reuse that data without contacting peers again. The size limit on incoming peer
requests remains in place.

An empty peer-discovery result is no longer cached permanently. A later request
can try discovery again; a successful nonempty result remains reusable. This
does not introduce an automatic retry loop within a playback request.

## Keep HLS response memory accounted for

Origin HLS response ownership now follows emitted body bytes. A client retaining
a body clone or a streamed slice also retains the associated resource permits,
even after the response stream reaches EOF or is dropped. This prevents the
concurrency budget from being released while its buffered media is still alive.

## Bound bencode container amplification

The generic bencode parser limits each parsed value to 65,536 nodes, counting
dictionary keys as well as values, in addition to nesting depth. Oversized
shallow containers and repeated dictionary keys can no longer allocate an
unbounded number of parse nodes from
a comparatively small incoming message. Normal messages and prefix parsing
retain their existing behavior.

## Qualification

Regression tests cover large cached VOD ranges with memory and disk stores,
response bytes retained after EOF, cancellation and stream drop, and parser
limits at their exact boundary. The release candidate also runs the full Rust,
synthetic HLS/replay, security and six-target fuzz checks.

This is a beta release. It does not replace stable binary downloads or the
container `latest` channel. The changes do not add a programme archive or alter
deployment defaults. Offline qualification does not establish playback quality
for every public source or client device.
