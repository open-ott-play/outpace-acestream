# Outpace 0.9.4-beta.2

This beta fixes the jemalloc startup warning on macOS:
`option background_thread currently supports pthread only`.

The previous build enabled background threads through a Cargo feature even on
macOS, where the bundled jemalloc does not support them. Its runtime configuration
also used an unprefixed symbol, although macOS jemalloc requires a prefixed symbol.

The allocator configuration now uses the correct platform symbol and C pointer
layout. macOS retains jemalloc, memory statistics and explicit decay settings,
without enabling unsupported background threads. Linux retains background purging.
This does not add an idle-time purge worker to macOS.

Native startup checks require a successful version response with empty standard
error. Runtime allocator tests also check the effective configuration. The macOS
checks run on both Apple Silicon and Intel before merge and in source RC validation;
release packaging checks the actual executable on native build targets.

This beta includes the VOD cache, peer discovery, HLS memory accounting and bencode
limits from 0.9.4-beta.1. It does not replace the stable release or the container
`latest` channel.
