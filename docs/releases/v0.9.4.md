# Outpace 0.9.4

This release carries forward the fixes qualified in 0.9.4-beta.1 and beta.2.

- Reuse verified retained VOD pieces across peer-sized blocks and allow a later
  request to retry empty peer discovery. Incoming peer request limits remain.
- Keep origin HLS memory permits attached to retained response bytes, including
  clones and slices kept after EOF or stream cancellation.
- Limit bencode values to 65,536 parse nodes, including dictionary keys.
- Use the correct jemalloc configuration symbol and C pointer layout on macOS.
  macOS no longer enables unsupported background threads; Linux retains
  background purging. Native startup and allocator checks cover both Mac
  architectures.
- Refresh the pinned shared security workflow while preserving the source RC
  and six-target fuzz requirements.

The release process requires fresh source checks and RC evidence for the final
version commit, then all seven binary/source package pairs and all three
container architectures. Prior beta evidence remains tied to its original
source; these notes do not assert acceptance before those checks complete.

Existing deployment defaults and experimental feature limits remain unchanged.
This release does not add a programme archive or establish playback quality for
every live source or client device.
