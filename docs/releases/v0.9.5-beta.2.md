# Outpace 0.9.5-beta.2

This beta includes the replay-memory and metadata corrections from
[0.9.5-beta.1](v0.9.5-beta.1.md), then improves live scheduling and recovery.

- Equal-capacity peer selection preserves usable coverage instead of stranding
  a narrow peer's slot when a broader peer can serve later pieces.
- A bounded mean of 100 accepted whole-piece service intervals refines otherwise
  equal peer choices. All tied candidates must have fresh measurements; unknown
  timing preserves the previous deterministic order. Retries, mixed ownership,
  duplicates and partial data retained across reconnects cannot teach a false
  speed. Capacity and window priorities remain primary.
- Draining contiguous completed media immediately advances the shared request
  floor, stopping queued obsolete chunk requests before output backpressure can
  delay publication. A write already in progress may finish.
- Ready-empty source reads yield during startup collection and pass-through.
  An expired startup deadline takes priority over a ready source discontinuity,
  preserving already-buffered media and the next payload's gap marker.
- Protocol notes correct earlier Python-bytecode assumptions and document the
  verified native timing, underrun and request-reconciliation contracts. No
  original engine code is copied or required at runtime.

HTTP configuration and production timeout values are unchanged. The timing
refinement is not a global minimum-ETA scheduler, and runtime gaps do not restart
global buffering for all viewers. Native player-driven pause/autoresume needs
a separate integration design. Real-channel startup improvement, complete native
engine parity, persistent DVR and provider archives are not claimed.

The beta provides seven native binary targets and their corresponding complete
AGPL source archives, plus a three-platform container image. Availability and
publication state are authoritative on the
[release page](https://github.com/open-ott-play/outpace-acestream/releases/tag/v0.9.5-beta.2).
Stable qualification uses the mandatory source RC, including all six fuzz
targets; this beta is not the stable channel.
