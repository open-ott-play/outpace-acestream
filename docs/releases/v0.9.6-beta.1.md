# Outpace 0.9.6-beta.1

This beta selectively adapts useful upstream changes while preserving our managed
origin HLS, retained replay and live recovery work.

- Live descriptor identity includes all nine optional protocol fields in their
  correct order, preserving present zero and empty values. Legacy wrapped VOD
  retains its separate identity rules.
- Protected and malformed descriptors return distinct errors before playback.
  The checks also cover retained VOD owners and warm HLS segment routes;
  inspection does not grant playback permission or catalog authority.
- Bounded peer reads, borrowed live payloads and one-buffer encoding reduce
  temporary copying without changing message limits or per-I/O deadlines.
- Reciprocal reads and output-capacity waits leave the peer-control loop
  responsive. Accepted pending media survives pool replacement with its ordering
  and discontinuity boundaries. Productive credit is recorded only after enqueue.
- Buffer statistics use bounded incremental scans. Native
  `livepos.buffer_complete` distinguishes an unfinished measurement from a known
  empty buffer; compatibility API keys remain unchanged.
- Optional `OUTPACE_MAX_SESSIONS` counts pending provider acquisitions and
  retained source/content owners, including VOD range readers. The default `0`
  remains unlimited. Saturation returns HTTP 503 with `Retry-After: 1`.

Session admission is not a process-memory, viewer or retiring-socket ceiling.
Managed origin HLS retains its separate relay limit, and existing byte budgets
remain in force. No network setting, buffering target or timeout default changes.
Some existing store-publication, activation and gossip waits remain outside this
adaptation. See the [provenance and scope note](../protocol/notes/75-selected-upstream-adoption.md).

Synthetic regression and decoded-media tests cover the implemented contracts.
They do not establish faster real-channel startup, complete original-engine
parity or provider archives. Mutational fuzzing remains mandatory for an explicit
source RC; ordinary beta publication does not start that campaign.

The beta provides seven native binary targets with corresponding complete AGPL
source archives and a three-platform container image. Check the authoritative
[release page](https://github.com/open-ott-play/outpace-acestream/releases/tag/v0.9.6-beta.1)
for publication and downloadable assets. This prerelease updates the container
`beta` channel; stable downloads and container `latest` remain separate.
